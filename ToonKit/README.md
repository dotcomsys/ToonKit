# ToonKit — WoW Forever

Version 0.10 Alpha for WoW Forever, Interface 16001.

**License and credits.** ToonKit is distributed under GPL-3.0-only. Journey includes independently authored ToonKit routes and an optional GPL-licensed Polestar guide source. Choose it in Journey > Leveling campaign. Quest facts and other datasets retain their original notices. See [LICENSE.txt](LICENSE.txt), [SOURCES.md](SOURCES.md) and [Licenses](Licenses/).

Use /tk for the journal, /tk dungeons for dungeon search, /tk gear for the equipment finder, /tk bags for categorized player bags, /tk world for the Books journal, and /tk settings for configuration. Bank interaction uses Blizzard's banker frame. See [Quick start](QUICKSTART.md) for the current navigation paths.

The watched-quest tracker uses native quest watches, difficulty colors, zone groups, collapse controls and right-click Untrack. Click a title for native quest details. Shift-click untracks, or links to an active chat edit box. Ctrl-drag the corner to resize. Right-click the header for layout controls. Overflow scrolling is optional and off by default; no watched quests are redirected to a “more quests” log link.

Journey shows the current task with Skip task, Pause and Map. The Guide tools menu includes Undo, preparation, timing and history. Gear targets are shared with dungeon loot and Equipment. Start hunt preserves the prior route. Native quest reward annotations display compact upgrade status. The player chooses, equips and sells items.

Book collection and donation are separate states. The source-backed catalog has disputed/unavailable entries excluded; pickup locations remain community reports where noted. Native collection evidence takes precedence. Native AH assistance uses observed asking prices, not guaranteed sale proceeds, and never automatically posts or buys.

Current item facts, equipment eligibility and talent observations come from the native Forever client. Unsupported old-build effect models do not enter ordinary recommendations. Gear scores are advisory stat estimates, not universal BiS or measured DPS. Missing source facts remain unknown.

Source provenance and notices are retained in SOURCES.md, SOURCE-MANIFEST.json and Licenses/. The combined addon is distributed under GPL-3.0-only with the required corresponding licensed inputs. Reproduce current authored dungeon/library data using tools/Import-LiveForever.py in the development workspace. Never distribute an unmatched addon/source pair.

The source companion includes the editable add-on, build tools and corresponding inputs. Historical research exports remain in the development workspace. In-game acceptance is pending.
